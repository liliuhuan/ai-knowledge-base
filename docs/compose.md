# 🔍 附注
- **周期判断逻辑**：  
  中国及全球经济周期大致遵循“复苏→过热→衰退→萧条”四阶段。  
  资产表现先后顺序通常为：**利率债 → 股票 → 商品 → 黄金 → 现金**。  
- **你的组合特点**：  
  - 红利+消费占比高 → 稳健、防御性较好  
  - 科技与周期仓位适中 → 有进攻潜力  
  - 黄金与现金配置齐备 → 拥有下行对冲能力
