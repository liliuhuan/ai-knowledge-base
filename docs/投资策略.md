当前网页的主要内容是关于**LagomA账户投资组合**的要素说明，重点涵盖以下几点：

1. **超额收益的来源**：
   - 强调通过灵活资产配置和低换手原则实现低成本交易。
   - 倾向于选择能逐年创造内在价值的优质公司，规避价值毁灭型公司和新股中长线配置。
   - 通过年均净资产收益率（ROE）、股息率和打新套利收益实现投资增速。
   - 利用市场周期性躁动，在低估时买入更多资产，高估时卖出溢价筹码。

2. **调仓频率**：
   - 整体头寸以长线标的为主，有数只个股已持有超过五年。
   - 卖出或换股理由包括公司基本面不可逆下滑、价格严重高估、有更好的选择。
   - 强调“低频交易”降低交易成本和税负，为个人投资者赢得更多时间。

3. **控制回撤的心得**：
   - 建议股票至少配置5至8个，涉及三个行业以上。
   - 个股市值规模按大/中/小盘适度均衡搭配。
   - 使用ETF等指数品种比持个股更安全、省心。
   - 个股过热时切勿增持长线仓。
   - 资产达一定规模后，增配跨市场QDII组合对冲。
   - 保留适量现金仓，参与低风险策略。

4. **关于杠杆**：
   - 适度接受融资，在事业上升期和现金流宽裕时利用人力资本优势。
   - 早年资金规模有限时设定的融资比例上限为30至40%，现今融资上限已严控至20%以下。
   - 建议经验有限的普通投资者不要轻易使用杠杆，负债总额应尽量不超过自己未来五年的现金收入总和。
